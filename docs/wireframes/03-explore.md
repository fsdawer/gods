## TagFeedScreen — 태그별 피드

```
┌─────────────────────────────┐
│ ← #코딩공부            1.2k │  ← 헤더 + 포스트 수
├─────────────────────────────┤
│                             │
│  ┌───────────────────────┐  │
│  │ [포스트 카드들...]     │  │
│  └───────────────────────┘  │
│                             │
└─────────────────────────────┘
```

## 동작 흐름

1. 화면 진입 → GET /api/posts/explore + GET /api/tags/trending 동시 호출
2. 검색창 포커스 → GET /api/tags/search?keyword={text} 실시간 검색
3. 트렌딩 태그 탭 → TagFeedScreen({tagName}) 이동 → GET /api/posts/explore?tag={tagName}
4. 포스트 카드 탭 → PostDetailScreen 이동

## API 연동

| 액션 | API |
|---|---|
| 탐색 피드 | GET /api/posts/explore?limit=20&cursor={cursor} |
| 트렌딩 태그 | GET /api/tags/trending |
| 태그 검색 | GET /api/tags/search?keyword={text} |
| 태그별 피드 | GET /api/posts/explore?tag={tagName}&limit=20 |
