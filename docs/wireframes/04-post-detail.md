## 동작 흐름

1. 화면 진입 → GET /api/posts/{id} + GET /api/posts/{id}/comments 동시 호출
2. 좋아요 버튼 탭 → POST /api/posts/{id}/like 또는 DELETE
3. 아바타/닉네임 탭 → UserProfileScreen 이동
4. 댓글 입력 후 전송 → POST /api/posts/{id}/comments
5. 내 댓글 길게 누름 → 삭제 확인 → DELETE /api/posts/{id}/comments/{cid}
6. 삭제 버튼(내 포스트) → 확인 다이얼로그 → DELETE /api/posts/{id} → 뒤로 이동

## API 연동

| 액션 | API |
|---|---|
| 댓글 조회 | GET /api/posts/{id}/comments |
| 댓글 작성 | POST /api/posts/{id}/comments |
| 댓글 삭제 | DELETE /api/posts/{id}/comments/{cid} |
| 좋아요 | POST /api/posts/{id}/like |
| 좋아요 취소 | DELETE /api/posts/{id}/like |
| 포스트 삭제 | DELETE /api/posts/{id} |
