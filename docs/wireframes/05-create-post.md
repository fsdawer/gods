## TodoCertForm — 투두 인증 작성

```
┌─────────────────────────────┐
│ ✕  새 포스트         작성   │
├─────────────────────────────┤
│  [자유 글 ○]  [투두 인증 ●]  │
├─────────────────────────────┤
│                             │
│  투두리스트 선택             │
│  ┌───────────────────────┐  │
│  │ 오늘의 투두 (06/07)   │  │  ← 투두 목록 카드
│  │ ✅ 알고리즘 5문제       │  │
│  │ ✅ 영어 단어 20개      │  │
│  │ ⬜ 독서 1시간          │  │
│  └───────────────────────┘  │
│                             │
│  ┌───────────────────────┐  │
│  │ 인증 한마디            │  │
│  │ (선택사항)             │  │
│  │                       │  │
│  └───────────────────────┘  │
│                             │
│  #태그 입력...               │
│  [#공부] [#갓생]  ✕         │
│                             │
└─────────────────────────────┘
```

## 동작 흐름

### 자유 글
1. 텍스트 입력 → (선택) 이미지 탭 → 갤러리 열기 → POST /api/images/presigned-url → S3 PUT → imageUrl 확보
2. 태그 입력 → Enter/스페이스로 태그 추가
3. 작성 버튼 → POST /api/posts → FeedScreen으로 이동

### 투두 인증
1. GET /api/todos → 오늘 투두 목록 표시
2. 인증 문구 입력, 태그 입력
3. 작성 버튼 → POST /api/todos/{id}/certify → FeedScreen으로 이동

## API 연동

| 액션 | API | 요청 |
|---|---|---|
| 이미지 Presigned URL | POST /api/images/presigned-url | { fileName, contentType } |
| 자유 포스트 생성 | POST /api/posts | { content, imageUrl?, tags[], type:"FREE" } |
| 투두 인증 포스트 | POST /api/todos/{id}/certify | { content?, tags[] } |
| 투두 목록 조회 | GET /api/todos | - |
