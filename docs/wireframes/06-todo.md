
## 동작 흐름

1. 화면 진입 → GET /api/todos (오늘 날짜 기준)
2. 날짜 ◀▶ 탭 → 날짜 변경 후 재조회 (과거 날짜는 읽기 전용)
3. 항목 체크 탭 → PATCH /api/todos/{id}/items/{iid} (즉시 반영)
4. 인증 포스트 버튼 탭 → CreateModal(TodoCertForm) 열림 with todoId
5. + 추가 버튼 → 투두 추가 모달 → POST /api/todos
6. ⋮ 메뉴 → 삭제 → DELETE /api/todos/{id}

## API 연동

| 액션 | API | 요청 |
|---|---|---|
| 투두 목록 | GET /api/todos | - |
| 투두 생성 | POST /api/todos | { title, items: [{content}] } |
| 투두 삭제 | DELETE /api/todos/{id} | - |
| 항목 체크 | PATCH /api/todos/{id}/items/{iid} | { completed: boolean } |
