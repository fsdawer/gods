## 동작 흐름

### MyProfileScreen
1. 화면 진입 → GET /api/users/me
2. 프로필 수정 버튼 → EditProfileScreen 이동

### UserProfileScreen
1. 화면 진입 (userId 파라미터) → GET /api/users/{id} (엔드포인트 없음 — me 기준으로 렌더링)
2. 팔로우 버튼 → POST /api/users/{id}/follow
3. 팔로잉 버튼 탭 → DELETE /api/users/{id}/follow

### EditProfileScreen
1. 화면 진입 → 현재 정보 표시
2. 사진 변경 → 갤러리 → POST /api/images/presigned-url → S3 PUT
3. 저장 → PATCH /api/users/me

## API 연동

| 액션 | API | 요청 |
|---|---|---|
| 내 프로필 | GET /api/users/me | - |
| 프로필 수정 | PATCH /api/users/me | { nickname?, bio?, profileImageUrl? } |
| 팔로우 | POST /api/users/{id}/follow | - |
| 언팔로우 | DELETE /api/users/{id}/follow | - |
