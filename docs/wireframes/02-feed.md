## 포스트 카드 종류

| 타입 | 표시 내용 |
|---|---|
| FREE | 텍스트 + 이미지(선택) + 태그 |
| TODO_CERT | 투두 체크리스트 카드 + 인증 텍스트 + 태그 |

## 동작 흐름

1. 화면 진입 → GET /api/posts?limit=20 호출
2. 스크롤 하단 도달 → GET /api/posts?cursor={lastCursor}&limit=20 추가 로드
3. 포스트 카드 탭 → PostDetailScreen 이동
4. 아바타/닉네임 탭 → UserProfileScreen 이동
5. 좋아요 버튼 탭 → POST /api/posts/{id}/like 또는 DELETE

## API 연동

| 액션 | API |
|---|---|
| 피드 조회 | GET /api/posts?limit=20&cursor={cursor} |
| 좋아요 | POST /api/posts/{id}/like |
| 좋아요 취소 | DELETE /api/posts/{id}/like |
