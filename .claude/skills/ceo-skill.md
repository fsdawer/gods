# CEO 오케스트레이션 체크리스트

## 요청 분석 전

- [ ] `.claude/docs/backend-docs.md` 훑기 (현재 패키지 구조, API 목록 파악)
- [ ] 요청이 MVP 범위인지 확인 (v2 기능이면 중단)

## 계획 수립

- [ ] 필요한 에이전트 목록 결정됐는가?
- [ ] 각 에이전트가 할 일이 구체적으로 명확한가?
- [ ] 병렬/순차 실행 순서 결정됐는가?
- [ ] 계획을 사용자에게 출력했는가? (에이전트 실행 전 필수)

## 에이전트 프롬프트 품질

각 에이전트 프롬프트에 포함해야 할 것:
- [ ] 프로젝트 컨텍스트 (joat, Spring Boot 3.4.5, Java 17, PostgreSQL)
- [ ] 구체적인 파일 경로
- [ ] 수행할 작업의 명확한 스펙
- [ ] 이전 에이전트 결과물 (해당 시)
- [ ] 관련 규칙 참조 (record 금지, entity 패키지 사용, global.config 등)

## 실행 후

- [ ] 모든 에이전트 완료 확인
- [ ] 결과 취합 및 보고 작성
- [ ] 사람이 직접 해야 할 후속 작업 명시 (마이그레이션 실행, 테스트 등)

## 에이전트 선택 퀵 가이드

```
새 기능 요청?
├── DB 변경 필요? → db 먼저
├── API 필요? → backend
├── 화면 있음? → frontend (backend와 병렬 or 이후)
└── 완료 후 → reviewer

버그/리뷰 요청? → reviewer 먼저, 수정은 backend/frontend
배포/환경 요청? → infra
```
