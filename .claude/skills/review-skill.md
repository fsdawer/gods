# 코드 리뷰 체크리스트

## 작업 시작 전

- [ ] `.claude/docs/review-docs.md` 읽기 (전체 체크리스트, 컨벤션 기준)
- [ ] 변경 파일 목록 파악 (`git diff --name-only`)

## 구조 규칙 검토

- [ ] 엔티티가 `*/entity/` 패키지에 있는가? (`*/domain/` 폴더 사용 금지)
- [ ] 설정 클래스가 `joat.global.config`에 있는가?
- [ ] DTO에 `record` 사용 없는가?
- [ ] 서비스 레이어가 인터페이스 + 구현체로 분리됐는가?
- [ ] Controller/Service가 인터페이스 타입으로 주입받는가?

## 보안 검토

- [ ] JWT 검증 누락 엔드포인트 없는가?
- [ ] 민감 정보 로그 없는가?
- [ ] SQL Injection 가능성 없는가?

## 성능 검토

- [ ] N+1 쿼리 발생 가능성 없는가?
- [ ] 카운터 캐시(`like_count`, `comment_count`) COUNT 쿼리로 가져오지 않는가?

## 결과 형식

```
## 리뷰 결과

### 🚨 블로커 (반드시 수정)
-

### ⚠️ 권고 (수정 권장)
-

### 💡 제안 (선택 개선)
-

### ✅ 잘 된 점
-
```
